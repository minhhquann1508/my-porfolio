# Nguyễn Minh Quân — Portfolio

A blueprint / IFC-viewer themed portfolio. Each project is a storey of a 3D building you can rotate and inspect.

Built with Next.js 15, React Three Fiber and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Content

All text lives in `src/data/profile.ts` — profile, projects (storeys), timeline, skills, about and achievements.
Set `github` / `linkedin` there to show those buttons.

## Deploy

Import the repository on [Vercel](https://vercel.com/new) — no extra configuration needed.
